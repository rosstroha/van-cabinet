# Van Cabinet

The cabinet is a galley type cabinet for a 2023 MB Sprinter 170 conversion. It should ideally house a grey water tank and a toilet. The dimensions can be dictated by these items as well as other physical limitations so long as the user approves of the dimensional change first.

Both the toilet and grey water tank need to be decided upon still. The length of the trips in this van are usually for the weekend or sometimes a week at most. The agent should suggest RV specifc components for the grey water tank and toilet based on the usage of the van.

Use images as a reference.

Ask clarifying questions when needed.

The PDF is the CAD drawing for the bed which will this cabinet will go next to. Use its asthetics (the vent slots) when designing. Use its dimensions to make sure the cabinet will fit nicely next to the bed. Measurements are also included in the photos.

Design it such it can be CNC'd on a bed no wider than 48".

Save all generated code and scripts to this directly for future and possible re-use.

Use multiple agents for running commands which are verbose, when generating code, researching, fetching dimensions of components, etc.

## Requirements

- Height should be 33". This is negotiable.
- There should be a sink and it needs to be on the left.
- Create a Fusion360 file for editing or importing into F360.
- Follow the basic layout depicted in the drawings.
- The design follows the bed's asthetics. Use the style of door that the bed has (frameless, full overlay).
- The width should NOT be greater than 30 1/8". This is important because it needs to not go over the edge of the side step.
- The cabinet needs to account for the C-pillar which sticks out. The C-pillar dimensions protrudes at 5/8" D x 4 1/2" H x 6" W.
- There needs to be a way to slide out the toilet. The drawer slides should be sturdy enough for someone to sit on or if there are no drawer slides, some way to move it in/out easily.
- The grey water tank needs to be accessible to be emptied.
- The design needs to be space efficient.
- There needs to be another platform which comes out above the toilet which has locking drawer slides. It will serve as a platform for dogs to use to more easily access the bed. The width should be roughly half of the cabinet. It's depth should be 12".
- Include a way for water lines to run from the side of the bed into the side of this cabinet. There are currently no holes or water lines going to/from the side of the bed.
- The design should be parameterized.
- Mounting will be done via self-drilling stainless steel screws with pan heads and washers OR using rivet nuts and 1/4-20 bolts + washers.
- The design needs to consider that the cabinet will be in a moving vehicle.
